# drama-copyright-check-skill

[![License](https://img.shields.io/badge/license-Proprietary-red)](./LICENSE)

**短剧剧本版权侵权分析工具** —— 基于中国著作权法司法实践，对短剧剧本进行结构化版权侵权分析，输出人物对照表、剧情对照表及综合风险评估。

---

## 这是什么？

这是一个 [Codex](https://github.com/openai/codex) AI Skill，用于自动化分析短剧剧本的版权侵权风险。它实现了中国著作权法司法实践中的 **"抽象-过滤-比较"**（Abstract-Filter-Compare）三步法，帮助编剧、内容审核人员和法务人员快速判断两个剧本之间是否存在实质性相似。

### 典型使用场景

- 编剧收到"抄袭"指控，需要自查剧本与对方剧本的重合度
- 平台内容审核团队判断短剧是否存在版权风险
- 法务人员在著作权纠纷中快速获取初步分析结论
- 创作者整理自身剧本的人物关系和情节结构

---

## 核心功能

| 功能 | 说明 |
|---|---|
| 📋 **人物对照表** | 提取角色身份、性格、叙事功能，逐一对比并分析关系网络对应度 |
| 🎬 **剧情对照表** | 场景级情节节点提取，用 ★ 标注相似节点及其对应关系 |
| ⚖️ **法律框架分析** | 基于"抽象-过滤-比较"法，自动剔除不受保护内容（题材、公式桥段、扁平原型等） |
| 📊 **风险量化** | 计算人物相似密度和情节相似密度，给出低/中/高风险结论 |
| ✏️ **修改建议** | 针对高相似度的具体角色和情节节点，提供可操作的修改方向 |
| 📄 **格式导出** | 支持将分析结果导出为带样式的 `.docx` 文件 |

## 快速开始

### 前置要求

- 安装 [Codex](https://github.com/openai/codex)
- Python 3.8+

### 1. 安装 Skill

```bash
# 将本仓库克隆到 Codex skills 目录
git clone https://github.com/QAyong/drama-copyright-check-skill.git $CODEX_HOME/skills/drama-copyright-check
```

### 2. 安装 Python 依赖（按需）

```bash
pip install python-docx pdfplumber pyperclip

# 处理 .doc 格式需额外安装
pip install pywin32
```

### 3. 预处理剧本（可选，大文件建议执行）

```bash
# 将剧本文件转换为纯文本并自动分段
python prepare.py 我的剧本.docx
python prepare.py 对比剧本.pdf
```

- 支持格式：`.txt` / `.docx` / `.doc` / `.pdf`
- 超过 **8 万字** 自动按分集标记切分，无标记则按 5 万字均分

### 4. 使用 Skill 进行版权分析

在 Codex 对话中直接提及触发关键词即可激活：

> "帮我分析一下这个剧本有没有版权风险"
> "对比一下这两个剧本"
> "看看我的剧本和对方剧本的相似度"

Skill 将自动执行：
1. 输入识别（单剧本 / 双剧本）
2. 人物与情节提取
3. 生成两级对照表
4. 综合风险判断（仅双剧本）

### 5. 导出分析报告

```bash
# 从剪贴板导出
python export.py

# 从文件导出
python export.py 分析结果.txt
```

输出为带专业排版的 `.docx` 文件，可直接用于汇报或存档。

## 法律框架

本项目基于中国著作权法司法实践中的 **"抽象—过滤—比较"** 三步法：

| 处理层 | 内容 |
|---|---|
| **抽象** | 将作品从具体到一般进行逐层抽象，分离思想与表达 |
| **过滤** | 剔除题材标签、公式桥段、扁平原型、公有领域素材等不受保护内容 |
| **比较** | 对剩余的保护性表达（角色关系网络、情节链条、场景独特实现）进行比对 |

**关键阈值**：从被诉作品视角，当 **70%** 以上独创性表达与原作高度吻合时，实质性相似基本成立。

---

## 风险等级说明

| 等级 | 条件 | 含义 |
|---|---|---|
| 🟢 **低风险** | 人物相似密度 < 50% 且 情节相似密度 < 50% | 构成实质性相似的可能性较低 |
| 🟡 **中风险** | 任一密度在 50%–70% 之间 | 存在相似点，建议修改高重合度部分 |
| 🔴 **高风险** | 任一密度超过 70% | 实质性相似基本成立，需大幅修改 |

## 输出示例

### 人物对照表（双剧本模式）

| 角色 | 我方剧本人设 | 对方剧本人设 |
|---|---|---|
| 男主 | 霸道总裁，32岁，商业天才，性格冷酷但内心柔软，叙事功能：推动女主成长 | 霸道总裁，30岁，家族企业继承人，性格高冷，叙事功能：与女主构成欢喜冤家 |
| 女主 | 天才医生，28岁，善良坚韧，叙事功能：治愈男主的情感创伤 | 实习记者，25岁，乐观开朗，叙事功能：打破男主的高冷外壳 |
| **人物关系网络** | 男主×女主：治愈与被治愈 | 男主×女主：欢喜冤家→相知相爱 |

### 剧情对照表（双剧本模式，节选）

| 节点 | 我方节点名称 | 我方情节 | 对方情节 | 相似理由 |
|---|---|---|---|---|
| 1 | 初次相遇 | 医院走廊意外碰撞，女主救治男主的伤口 | 公司楼下意外碰撞，咖啡洒在男主西装上 ★对应我方1 | 情节装置相同：均为意外碰撞触发首次接触 |
| 2 | 契约婚姻 | 男主以资助医院为条件，要求女主假扮未婚妻 | — | — |

### 综合风险判断（节选）

**人物相似密度**：3/5 = 60%（男主、女主、反派管家构成实质相似）  
**情节相似密度**：8/20 = 40%（我方 20 个节点中 8 个与对方高度对应）  
**风险结论**：🟡 **中风险** —— 人物相似密度超过 50%，建议修改男主与女主的人设维度以降低角色重合度。
